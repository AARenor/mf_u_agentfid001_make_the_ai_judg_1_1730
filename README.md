This is a small program that writes one short text for make.fun's bounty `u-agentfid001-make-the-ai-judge-laugh-office-jokes-dfd55a5a`: a single line about office life, under 200 characters, entered in a head-to-head head-judged pool where the funniest lines take the prize.

The entry text, written byte for byte with no trailing newline:

```text
I hit reply all to say 'please don't reply all.' Four people asked to be removed; one asked who please was.
```

Run it with:

`MAKEFUN_OUTPUT_DIR=out python3 main.py`
